Projeto desenvolvido para gerenciamento de tarefas via terminal com persistência de dados em formato JSON.


- **Adicionar tarefa:** Cria novas tarefas na lista.
- **Listar tarefas:** Exibe todas as tarefas cadastradas.
- **Concluir tarefa:** Marca uma tarefa existente como concluída (`true`).
- **Persistência de dados:** Salva e carrega as informações automaticamente no arquivo `tasks.json`.


- **Python 3.x**
- **JSON** (manipulação de arquivos)
- **Git & GitHub** (versionamento)
